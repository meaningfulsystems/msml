## Appliance Review Notes

### Toaster

The toaster abstraction remains commercially plausible for a common pop-up toaster. It keeps the important core concepts: user lever/carriage interaction, heating element, browning/timer control, thermal cutoff/cancel behavior, power interaction, and user interaction.

Non-blocking simplifications retained for v1.0:

- Slot geometry is not modeled separately from the carriage.
- Crumb tray is omitted.
- Bagel, defrost, and reheat modes are omitted.
- Detailed electromechanical latch behavior is abstracted into lever, timer, carriage, and thermal cutoff behavior.

These omissions are acceptable for a compact all-diagram modeling example.

### Blender

The new blender model is inspired by common high-performance blender architecture without branding it as a Vitamix product. It includes motor base, motor, drive coupling, container, blade assembly, lid, tamper, control panel, and smoothie-complete sensor.

The smoothie-complete sensor is modeled as estimating smoothie completion from load, vibration, and texture proxy signals. When smoothness reaches the configured threshold, the sensor signals completion, the control panel stops the motor, and the state machine transitions from Blending to Complete.
